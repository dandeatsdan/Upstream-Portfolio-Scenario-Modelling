# Testing and Validation

This folder contains the principal testing and validation evidence for the Oil and Gas LTP Scenario Modeller prototype.

## Contents

| Artefact | Purpose |
|---|---|
| [Business Validation](business-validation.pptx) | Main pack summarising the five business-validation checks, stakeholder feedback and overall findings. |
| [Operations Testing](operations-testing.pptx) | Detailed evidence demonstrating the behaviour and resulting profile changes for each scenario operation. |
| [Performance and Scalability](performance-and-scalability.pdf) | Summary of controlled testing across increasing case volume, scenario volume and transformation complexity. |
| [Technical SME Walkthrough](technical-sme-walkthrough.docx) | Record of the technical demonstration, questions raised, architectural challenge and follow-up considerations. |

## Evidence handling

Commercially sensitive model outputs and underlying data are retained in the appropriate Secret SharePoint location and are not duplicated in this repository.
