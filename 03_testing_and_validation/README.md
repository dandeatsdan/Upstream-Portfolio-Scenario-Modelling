# Testing and Validation

This folder contains the principal testing and validation evidence for the Oil and Gas LTP Scenario Modeller prototype.

## Contents

| Artefact                                                       | Purpose                                                                                                                                                                                                                                                                                                                                 |
| :------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Business Validation](evidence/01_business-validation.pptx)                | Main validation pack integrating five checks: Plan Book activity-cut replication, scenario-operation testing and SME review, A&D dilution-case replication, manual-input and timing-adjustment validation, and the stakeholder survey. It brings the evidence together to present the overall findings, limitations and recommendation. |
| [Operations Testing](evidence/02_operations-testing.pptx)                  | Detailed testing of the scenario-modelling operations available within the prototype. It records the configurations tested, expected behaviour, resulting financial-profile changes and conclusions, demonstrating that operations were applied consistently across cases, scenarios and model years.                                   |
| [Performance and Scalability](evidence/03_performance-and-scalability.pdf) | Summary of controlled performance testing across increasing case volumes, scenario volumes and transformation complexity. It records the test method, measured runtimes and output volumes, including testing of the full 144-case population aligned to the Plan Book activity cut across five scenarios.                              |
| [Technical SME Walkthrough](evidence/04_technical-sme-walkthrough.pdf)     | Supporting record of the technical demonstration and review, including the model architecture, processing approach, questions raised, technical challenge, limitations and considerations for future industrialisation.                                                                                                                 |
| [Business SME Walkthrough](evidence/05_business-sme-walkthrough.pdf)          | Supporting record of the business SME walkthrough, including the meeting notes, questions and answers, presentation used during the session, and invitation email documenting the event and its purpose.                                                                                                                                |

## Evidence handling

Commercially sensitive model outputs and underlying data are retained in the appropriate Secret SharePoint location and are not duplicated in this repository.
