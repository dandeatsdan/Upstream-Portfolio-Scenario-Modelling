# User Guides

The [Application User Guide](application_user_guide.pdf) follows the workflow in the [Excel Scenario Modelling Application](../01_excel_application/05_working_solution/scenario_modelling_application.xlsm). It explains how to refresh inputs, select modelling cases, choose operations and enter parameters, check validation status, run the scenario engine, refresh outputs and compare results.

The guide also explains Financial Entity to Modelling Case translation, how to add a manual modelling case using the standardised template, and which operations are available during scenario configuration.

See the [Excel Application README](../01_excel_application/README.md) for implementation details and the representative datasets used by the workbook.
