# Project Management

The [Project Management Plan](project_management_plan.pdf) records the project objectives, initial scope, delivery phases and milestones. It covers the data acquisition and transformation plan, governance and accountabilities, stakeholder engagement, risks and dependencies, and the criteria for validation and closure.

See the [Development Journal](../06_development_journal/README.md) for how delivery evolved and [Testing and Validation](../03_testing_and_validation/README.md) for the evaluation evidence.
